# Euler's Melting Pot

[Project Euler](https://projecteuler.net/), with a different programming language for every problem. Once a language is used, it is retired and never used again.

Inspired by [Mercerenies/eulers-melting-pot](https://github.com/Mercerenies/eulers-melting-pot).

Every problem gets its own numbered folder containing the solution, whatever interpreter it needs, and a README explaining how it actually works.

## Rules

Common sense, mostly. What I'm actually holding myself to:

* One language per problem. No reuse.
* Dialects count as separate languages only when they genuinely differ. Python 2 and Python 3 are the same language here. Scheme and Common Lisp are not.
* The language does not have to be Turing complete, or even be a programming language. Spreadsheets, build systems and text editors are fair game.
* The answer has to be printed in a form a human can read. Printing the character whose codepoint is 233168 does not count.
* The work happens in the language. Calling a library that solves the problem is not a solution.
* Interpreters are taken as-is. If the interpreter has a bug, that bug is part of the language.
* If the language is obscure enough that you can't easily go download an interpreter, the folder ships one.
* Every folder gets a README. A solution nobody can read is half a solution.
* Brute force is allowed, but if the language can express something better, it should.
